# Copilot instructions

- Make small, reviewable changes.
- Prefer existing project patterns over new abstractions.
- Ask for clarification before changing public APIs or deployment behavior.
- Include tests or validation steps for behavior changes.
- Keep explanations concise and focused on tradeoffs.
- Do not paste secrets, credentials, or customer data into prompts or generated files.
- Link to source-of-truth docs instead of copying long policy text.
